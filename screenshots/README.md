E-Commerce Customer Analytics Dashboard

Project Overview

The E-Commerce Customer Analytics Dashboard is an end-to-end data analytics project developed to analyze online retail sales data and generate meaningful business insights.

This project demonstrates the complete analytics workflow including:

- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- SQL-Based Business Analysis
- Interactive Power BI Dashboard Development
- Customer & Product Performance Analysis

The goal of this project is to help businesses understand customer purchasing behavior, sales performance, and revenue trends using data-driven insights.



 Technologies Used
